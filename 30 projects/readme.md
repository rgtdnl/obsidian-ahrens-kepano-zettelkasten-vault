# 30 Projects: one folder per piece of writing

**Purpose:** everything belonging to one specific project: outlines, drafts, to-do lists, comments, collected references. One subfolder per project.

The book: project notes "can be discarded or archived after the project is finished."

## Rules
- Keep project notes strictly separate from the slip-box.
- You may change or rearrange them freely; the slip-box is untouched.
- When drafting, collect the relevant permanent notes into the project folder. The notes stay in the slip-box; the project folder references them.
- No project? No folder. Don't create project folders for topics or areas.

## When starting a project
1. Create a subfolder in 30 projects.
2. Collect relevant notes from the slip-box (link or copy them in).
3. Arrange them in order. Look for gaps and redundancies.
4. Draft by turning notes into continuous text. Translate, don't copy.
5. On completion: move the folder to 40 archive, or delete it. Never leave it in 30.
