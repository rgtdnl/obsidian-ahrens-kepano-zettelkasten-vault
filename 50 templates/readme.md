# 50 Templates: fewer decisions, more thinking

**Purpose:** standard note formats so you never decide structure on the fly. One template per note type you actually use.

The book: simplicity is paramount, and reducing decisions frees mental energy for thinking.

## What to keep here
- **Literature note template:** frontmatter (source, author, year), key points, my thoughts.
- **Permanent note template:** type, created, idea in full sentences, source links, related links.
- **Index / MOC template** (optional, community adaptation).
- No template for fleeting notes: they must stay frictionless.

## Rules
- One format per note type, used consistently.
- Change a template only when you feel a real need, not for novelty.
- Templates are for structure, not content. Never let them grow into forms.

## Action
1. Create the two core templates (literature, permanent) on day one.
2. Add the MOC template when you write your first index note.
3. Review templates only when a note fights the format.
