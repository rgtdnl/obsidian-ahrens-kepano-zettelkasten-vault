# 20 Slip-box: the heart of the system

**Purpose:** permanent notes. Self-contained ideas, written as if for publication, connected to everything related. One idea per note.

The book: permanent notes are written as if for print, stored the same way in the same place, and never thrown away.

## What lives here
- **Permanent notes:** the ideas themselves.
- **Index / Maps of Content:** entry points listing links to a topic's notes. A community adaptation, not in the book. Keep them as maps, not filing cabinets.

## Rules
- **One idea per note.** If a note contains two ideas, split it.
- **Full sentences, self-contained.** Your future self must understand it without the original context.
- **Reference sources and related notes.** Link, don't sort.
- File each new note behind the note it continues, and link both ways.
- Ask: "In which context will I want to stumble upon this again?" not "Which topic does it belong to?"
- Never put fleeting, project, or raw notes in here. Permanent notes only.

## Daily action
1. Review today's literature and fleeting notes.
2. Write 3-6 permanent notes (Luhmann averaged 6).
3. For each: does it contradict, correct, support, or add to what exists? What questions does it trigger?
4. Link it to related notes. Add it to an index if it opens a new thread.
5. Check backlinks on every note you touch. Follow threads, don't file.
