# 10 Literature: what the sources said

**Purpose:** literature notes, one per source idea, translated into your own words. The reference lives in the note template, so each note stays brief and self-explanatory.

The book: literature notes "can be very brief, as the context is clearly the text they refer to."

## Rules
- **Translate, never copy.** Rephrasing forces understanding; copying lets you skip it.
- **Be selective.** Capture only what resonates or may be useful later.
- **Always include the reference** (source, author, year, page) via the template.
- Store every literature note the same way in the same place.

## While reading
1. Read with a pen (or highlighter) in hand.
2. After each chapter or section, write 2-5 literature notes in your own words.
3. Ask: what is not mentioned? What must be true for this argument to hold?
4. File in this folder. Leave nothing half-done.

## Next step
Literature notes are raw material for permanent notes. When one sparks an idea of your own, write a permanent note in 20 slip-box and link it back here.
