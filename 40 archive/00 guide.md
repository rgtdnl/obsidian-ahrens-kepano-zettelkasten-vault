# 40 Archive: the bin for the indecisive

**Purpose:** finished project folders you can't quite bring yourself to throw away.

The book: "an archive, the bin for the indecisive."

## Rules
- Only finished project folders go here.
- **Permanent notes never go here.** They live in the slip-box forever. Archiving one breaks the system.
- Clippings and raw literature notes never go here. They are deleted after processing.
- Don't confuse this with archiving literature notes in your reference manager (Zotero). Different operation.

## When a project ends
1. Move its folder from 30 projects to 40 archive.
2. Leave it alone. Don't browse it for inspiration; the slip-box is for that.
3. If you never reopen an archived folder for a year, delete it.
